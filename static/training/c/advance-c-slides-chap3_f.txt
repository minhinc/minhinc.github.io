 <pre class="slidecontent">
 
- Define and initialize static array
- Array has to be initialized with constant variable that is qualified at compile time
</pre>
 <pre class="code">
int ia[get_size()]  // get_size() is function and resolved at run time
const int size=get_size(); // size resolved at run time
int ia[size]; // error
int ia[10*2-10]; // resolved at compile time</pre>
 <pre class="slidecontent">
 
- Local copy are uninitialized where as global copy is initialized to 0.
- Uninitialized stati c or global array goes to .bss section in the binary.
- Array is initialized in {} block
</pre>
 <pre class="code">
int arr[]={1,2,3} // array size 3</pre>
 <pre class="slidecontent">
or</pre>
 <pre class="code">
Int arr[3]={1,2,3}
Int arr[5]={1,2,3} // rest initialized with 0</pre>
 <pre class="slidecontent">
 
Uninitialized const array takes garbage value</pre>
 <pre class="code">
const int arr[3];// garbage value
 
C++ const uninitialized array is an error
const int arr[3]={1}; // rest initialized with 0
const int *arr=new arr[3]() // c++ value initialized</pre>
 <pre class="slidecontent">
 
Breaking array boundary is not an exception and it memory over writing</pre>
 <pre class="code">
int ary[1];
ary[2]=0;</pre>
 <pre class="slidecontent">
 
Function array arguments are actually pointer to array.</pre>
 <pre class="code">
void func(int ap[4]);
Void func(int ap[]);
void func(int *ap); //all are same
func (arr);</pre>
 <pre class="slidecontent">
 
-Pointer to array and multidimensional array</pre>
 <pre class="code">
void func(int (*arr)[10]);
void func(int arr[][10]);
void func(int arr[4][10]);// all same</pre>
 <pre class="slidecontent">
 
- Array can not be copied or assigned</pre>
 <pre class="code">
int ia2[](ia); // error
ia2 = ia1; //error</pre>
 <pre class="slidecontent">
 
- Array size can not be known.</pre>
 <pre class="code">
sizeof(arr)/sizeof(&arr[0])</pre>
 <pre class="slidecontent">
 
- Array memory management is in users hand. Chance of memory overwriting.
</pre>
 <pre class="code">
void func(int pa[6]){
pa[6]=8;
}
int pa[4];
func(pa);</pre>
 <pre class="slidecontent">
 
- Character array can be initialized with string null terminated.</pre>
 <pre class="code">
char ca[] = "C++";</pre>
 <pre class="slidecontent">
 
- Character array can be initialized character wise, many not be null
terminated</pre>
 <pre class="code">
char cal[] = {'C', '+', '+', '\0' };</pre>
 <pre class="slidecontent">
 
- In case of character strings use strn string function for manipulation, si.e</pre>
 <pre class="code">
strncpy, strncat.</pre>

- Dynamically allocating array, allocating on heap</pre>
 <pre class="code">
- void *realloc(void *ptr, size_t size);// buffer remain uninitialized
int pia = malloc(sizeof(int)*10); // uninitialized
 
- void *realloc(void *ptr, size_t size);// initialized buffer with char 0;
int pia=calloc(sizeof(int)*10);
 
- void *realloc(void *ptr, size_t size);// re-allocate uninitialized buffer of new size if continuous memory is available for new size.
int pia=malloc(sizeof(int)*10);
pia=realloc(sizeof(int)*20);</pre>
