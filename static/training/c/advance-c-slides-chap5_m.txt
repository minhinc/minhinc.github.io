   <ul class="slidecontent">
   <li class="big"><h2><a name="chap5_0">struct<br>- Structures and functions<br>- Array of structure<br>- Self referential structure<br>- Typedef<br>- Unions<br>- Bit-fields</a></h2></li>

<div class="clr"></div>
 <pre " class="slidecontent"> 
A structure is a collection of one or more variables, possibly of different types, grouped together under a single name for convenient handling.
A structure is user defined type.
All members are public.
  </pre>
 <pre " class="code">struct fraction{
int numerator;
int denominator;
}; </pre>
 <pre " class="slidecontent"> 
A struct declaration defines a type. The right brace that terminates the list of members may be followed by a list of variables, just as for any basic type.  That is,
  </pre>
 <pre " class="code">struct { ... } x, y, z; </pre>
 <pre " class="slidecontent"> 
is syntactically analogous to </pre>
 <pre " class="code">int x, y, z; </pre>
 <pre " class="slidecontent"> 
struct initialization
A structure can be initialized by following its definition with a list of initializers, each a constant expression, for the members:
  </pre>
 <pre " class="code">struct maxpt = { 320, 200 }; </pre>
 <pre " class="slidecontent"> 
Structure as member
  </pre>
 <pre " class="code">struct point{
int x;
int y;
};
 
 
struct rect{
struct point p1;
struct point p2;
};
 
struct {
int len;
char *str;
} *p;  //instantiation </pre>

- when two structures refer to each other, one must be declared in

  </pre>
