A structure is a collection of one or more variables, possibly of different types, grouped together under a single name for convenient handling.
A structure is user defined type.
All members are public.
</pre>
 <pre class="code">
struct fraction{
int numerator;
int denominator;
};</pre>
 <pre class="slidecontent">
 
A struct declaration defines a type. The right brace that terminates the list of members may be followed by a list of variables, just as for any basic type.  That is,
</pre>
 <pre class="code">
struct { ... } x, y, z;</pre>
 <pre class="slidecontent">
 
is syntactically analogous to</pre>
 <pre class="code">
int x, y, z;</pre>
 <pre class="slidecontent">
 
struct initialization
A structure can be initialized by following its definition with a list of initializers, each a constant expression, for the members:
</pre>
 <pre class="code">
struct maxpt = { 320, 200 };</pre>
 <pre class="slidecontent">
 
Structure as member
</pre>
 <pre class="code">
struct point{
int x;
int y;
};
 
 
struct rect{
struct point p1;
struct point p2;
};
 
struct {
int len;
char *str;
} *p;  //instantiation</pre>
 <pre class="slidecontent">
 
then</pre>
 <pre class="code">
++p-&gt;len</pre>
 <pre class="slidecontent">
Increments len, not p, because the implied parenthesization is ++(p-&gt;len).

 - pass by value

 <pre class="slidecontent">
 
 
Union
A union is a variable that may hold (at different times) objects of different types and sizes, with the  compiler keeping track of size and alignment requirements
 
union-name.member
or
union-pointer-&gt;member
</pre>
 <pre class="code">
union u_tag {
int ival;
float fval;
char *sval;
} u;</pre>
 <pre class="slidecontent">
 
The variable u will be large enough to hold the largest of the three types;
</pre>
 <pre class="code">
struct {
char *name;
int flags;
int utype;
union {
int ival;
float fval;
char *sval;
} u;
} symtab[NSYM];</pre>
 <pre class="slidecontent">
 
the member ival is referred to as</pre>
 <pre class="code">
symtab[i].u.ival</pre>
 <pre class="slidecontent">
 
and the first character of the string sval by either of</pre>
 <pre class="code">
*symtab[i].u.sval
symtab[i].u.sval[0]</pre>
 <pre class="slidecontent">

 <pre class="slidecontent">
 
Bit fields
If space is a serious concern, select the number of bits used for each member
A bit-field, or field for short, is a set of adjacent bits within a single implementation-defined storage unit that we will call a "word."
</pre>
 <pre class="code">
struct  {
unsigned int is_keyword:1;
unsigned is_extern: 1;
unsigned is_static: 1;
}flags;
 
flags.is_extern = flags.is_static = 1; //turn on
flags.is_extern = flags.is_static = 0; // turn off</pre>
 <pre class="slidecontent">
if (flags.is_extern == 0 && flags.is_static == 0) // to test them
 
Files are not arrays and they do not have addresses, so the &
operator cannot be applied on them.
 
Almost everything about fields is implementation-dependent. Whether a field may overlap a word boundary is implementation-defined.  Fields need not be names; unnamed fields (a colon and width only) are used for padding. The special width 0 may be used to force alignment at the next word boundary.</pre>
