 <pre " class="slidecontent"><b>-Procedural Method</b>
A document file (i.e. ButtonC.qml) can be crated as a <span style="color:#004000;">Component</span>, through <span style="color:#004000;">Qt.createComponent()</span>, with single root Item or through a <span style="color:#004000;">componentbbject</span> type that is declared in a document file itself. <span style="color:#004000;">Component</span> declared in a document file behave as an root Item 'declaration' which is 'defined' by <span style="color:#004000;">&lt;componentobject&gt;.createObject()</span> function. <pre class="note">&gt; If Qt.createComponent() is used, the creation context is the QQmlContext in which this method is called
