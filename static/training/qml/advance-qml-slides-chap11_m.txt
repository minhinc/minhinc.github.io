Various animations
<span style="color:#004000;">Transition</span> - Animates transitions during state changes
<span style="color:#004000;">SequentialAnimation</span> - Runs animations sequentially
<span style="color:#004000;">ParallelAnimation</span> - Runs animations in parallel
<span style="color:#004000;">Behavior</span> - Specifies a default animation for property changes
<span style="color:#004000;">PropertyAction</span> - Sets immediate property changes during animation
<span style="color:#004000;">PauseAnimation</span> - Introduces a pause in an animation
<span style="color:#004000;">SmoothedAnimation</span> - Allows a property to smoothly track a value
<span style="color:#004000;">SpringAnimation</span> - Allows a property to track a value in a spring-like motion
<span style="color:#004000;">ScriptAction</span> - Runs scripts during an animation
 
Types that animate properties based on data types
<span style="color:#004000;">AnchorAnimation</span> Animates changes in anchor values
<span style="color:#004000;">ColorAnimation</span> Animates changes in color values
<span style="color:#004000;">NumberAnimation</span> Animates changes in qreal-type values
<span style="color:#004000;">ParentAnimation</span> Animates changes in parent values
<span style="color:#004000;">PathAnimation</span> Animates an item along a path
<span style="color:#004000;">PropertyAnimation</span> Animates changes in property values
<span style="color:#004000;">RotationAnimation</span> Animates changes in rotation values
<span style="color:#004000;">Vector3dAnimation</span> Animates changes in QVector3d values

PropertyAnimation provides a way to animate changes to a property's value.  It can be used to define animations in a number of ways:
 
In a Transition </pre>

 <pre " class="slidecontent">Easing
Easing curves define how the animation will interpolate between the start value and the end value. Different easing curves might go beyond the defined range of interpolation. The easing curves simplify the creation of animation effects such as bounce effects, acceleration, deceleration, and cyclical animations,i.e Linear, Quad. For some curves,i.e. Easing.InOutElastic, amplitude, period and/or overshoot should also be mentioned.
  </pre>
 <pre " class="code">PropertyAnimation { properties: "y";
 easing.type: Easing.InOutElastic;
 easing.amplitude: 2.0;
 easing.period: 1.5 } </pre>

 <pre " class="slidecontent">There are two animation groups. SequentialAnimation and ParallelAnimation. They group contained animation sequentially and parallaly respectively. </pre>
 <pre " class="code">import QtQuick 2.0
Rectangle {
width: 100; height: 100
color: "red"
 MouseArea{
 anchors.fill:parent
 onClicked:seqid.start()
 }
 SequentialAnimation on color {
 id:seqid
 ColorAnimation { to: "yellow"; duration: 1000 }
 ColorAnimation { to: "blue"; duration: 1000 }
 }
} </pre>

</script></div> <pre " class="slidecontent">Once individual animations are placed into a SequentialAnimation or ParallelAnimation, they can no longer be started and stopped independently. The sequential or parallel animation must be started and stopped as a group.
 
Sharing Animation Instances
Sharing animation instances between Transitions or Behaviors is not supported, and may lead to undefined behavior.
  </pre>
 <pre " class="code">Rectangle {
// NOT SUPPORTED: this will not work correctly as both Behaviors
// try to control a single animation instance
NumberAnimation { id: anim; duration: 300; easing.type: Easing.InBack }
Behavior on x { animation: anim }
Behavior on y { animation: anim }
} </pre>
 <pre " class="slidecontent"> 
Solution </pre>
 <pre " class="code">// MyNumberAnimation.qml
NumberAnimation { id: anim; duration: 300; easing.type: Easing.InBack }
// main.qml
Rectangle {
Behavior on x { MyNumberAnimation {} }
Behavior on y { MyNumberAnimation {} }
} </pre>
