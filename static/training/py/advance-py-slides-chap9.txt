<pre class="slideabstract">Class is a template or a Pattern which is used to create similar type class instances/values</pre>
<div class="clr"></div>
 <pre  class="slidecontent">Class is a template or a pattern that can be used to create many instances of it. In programming terms it is a user defined <span style="font-style:Italic">type</span> for many value/instance objects.
Class definition leads to creation of class namespace which is represented by data structure <span style="font-style:Italic">class object</span>. Class namespace contains attributes. Attributes can be data type or function objects. Since every value has a type, a class object is of type <span style="font-style:Italic">type</span> class. <span style="color:#004000;font-weight:bold">type</span> is also known as meta class. </pre>
<div class="clr"></div> <pre style="float:left;" class="code">         <span style="color:#004000;">class</span> A:   &lt;----- class definition
          ca=<span style="color:#ff0000;">10</span>
          <span style="color:#004000;">def</span> cfunc(self):
           pass
     
            |               type <span style="color:#004000;">type</span> meta class
            |               ^ 
            | class object /
            v             /
     -------------------  |     +------  A <span style="color:#004000;">namespace</span>
     | <span style="color:#004000;">class</span> object 'A'|---     |
     -------------------        V
+-----&gt;| ca       |             A.ca=10
| +---&gt;| cfunc()  |             A.cfunc
| |    ------------
| |
| <span style="color:#004000;">attribute, function object</span>
<span style="color:#004000;">attribute, data type</span> </pre>
