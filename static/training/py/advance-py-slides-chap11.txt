  <h1><pre class="topic">  11. Meta Class</pre></h1>
   <ul class="slidecontent">
   <li class="big"><h2><a name="chap11_0">meta class</a></h2></li>   <li class="sml"><pre>class object
 - creation
 - initialization
</pre></li>   <li class="sml"><pre>instance object
 - Creation
 - Initialization
</pre></li>   <li class="sml"><pre>Modify class in meta class
</pre></li>   <li class="sml"><pre>Inheritance
</pre></li>   <li class="sml"><pre>Singleton</pre></li>
   </ul>
</div></a>
<div class="clr"></div>
 <pre  class="slidecontent">Every value has a type so a meta class is type of all class values. It is same as class is type of class instance object. <span style="font-style:Italic">type</span> is meta class of all classes. <span style="color:#004000;font-weight:bold">type</span> is available as class and <span style="color:#004000;font-weight:bold">type</span> is available as built in operator.
when a class is of type 'type' meta class, 'type' meta class provides <span style="font-style:Italic">factory method</span> __new__() which creates the class object. when instance object is of type class, class provides factory method __new__() which creates instance object.
<span style="background-color:#000" class="dot"></span> A class definition follows two heirarchy
 <span style="background-color:#000" class="dot2"></span> <span style="color:#004000;font-weight:bold">object</span> class inheritance where <span style="font-style:Italic">object</span> is base class of all classes
 <span style="background-color:#000" class="dot2"></span> <span style="color:#004000;font-weight:bold">meta class</span> inhertiance where <span style="font-style:Italic">type</span> is base class of all meta classes </pre>
<div class="clr"></div> <pre style="float:left;" class="codeb">           <span style="color:#004000;">object</span>        <span style="color:#004000;">type</span>
             ^             ^
             |             |
             ----+     +----
   &lt;&lt;base class&gt;&gt;|     |&lt;&lt;meta class&gt;&gt;
                 |     |
               ----------- equivalent to -------------------------
               |    <span style="color:#004000;">A</span>    | &lt;-----------&gt; |A(object,metaclass=type|
               -----------               ------------------------- </pre>

<div class="clr"></div> <pre  class="slidecontent">meta class can be used to create singleton class. singleton class can be instantiated only once. instantiating more time would return same (firstly created) instance object reference. instance object is created with function operator against class. </pre>
<div class="clr"></div> <pre  class="code">a=A() </pre>
<div class="clr"></div> <pre  class="slidecontent">creates instance object 'a' when class A is called function operator '()'. in this case type.__call__ function is called which in turn class 'object.__new__' and 'object.__init__' to created the instance object and then initialize them.
type.__call__ operator can be overloaded and calling type.__new__ and type.__init__ can be barred from second time onwards returning first time created instance object.
  </pre>
<div class="clr"></div> <pre  class="code">class Meta(type):
 def __call__(clsobj,*a,**kw):
  if not hasattr(Meta.__call__,'singleton'):
   setattr(Meta.__call__,'singleton',super(Meta,clsobj).__call__(*a,**kw))
  return getattr(Meta.__call__,'singleton') </pre>
