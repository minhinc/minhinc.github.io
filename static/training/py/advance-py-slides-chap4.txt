<div class="clr"></div>
 <pre style="float:left;" class="slidecontent">decorator is structural design pattern in 23 design patterns from GoF. decorator class comes as wrapper class of decoratee and adds extra functionality
<span style="color:#ff0000;">See also</span> <pre class="note"><a href="http://minhinc.42web.io/training/dp/advance-dp-slides.php?chap=5#chap5_2">decorator design pattern</a></pre>
in python a decoratee class function can be decorated by placing '@&lt;classname|function&gt;' before the function delclaration.'@&lt;classname|function&gt;' is decorator wrapper which returns actual decorator function. '@&lt;classname|function&gt;' is intialized once class object is created.
<span style="color:#ff0000;">See Also</span> <pre class="note"><a href="http://minhinc.42web.io/training/py/advance-py-slides.php?chap=11#chap11_1">Meta Class Object</a></pre>
<pre class="codei">
def decoratorfunc(f):
 print('decorator wrapper')
 def func():
  print('&gt;&lt;decorator func')
  f()
  print('&lt;&gt;decorator func')
 return func
 
class A:
 @decoratorfunc
 def func():
  print('decoratee func')
 
 
decorator wrapper
&gt;&gt;&gt; A.func()
&gt;&lt;decorator func
decoratee func
&lt;&gt;decorator func
&gt;&gt;&gt; A.func()
&gt;&lt;decorator func
decoratee func
&lt;&gt;decorator func
here A.func is decoratee where as func as local to decoratorfunc is decorator, decoratorfunc is wrapper and gets intialized at the time of class object creation.
 <span style="background-color:#000" class="dot2"></span> class decorator is actually function call operator. so it also a function decorator wrapper </pre>
