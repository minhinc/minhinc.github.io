 <span style="background-color:#000" class="dot2"></span> Factory method is used to create instance object. <span style="color:#004000;font-weight:bold">new</span> factory method creates instance object in c++ where as <span style="color:#004000;font-weight:bold">object.__new</span> creates instance object in python
 
<span style="background-color:#000" class="dot"></span> Dissimilarity
 <span style="background-color:#000" class="dot2"></span> Class object in c++ is created by compiler and there is no concept of meta class.
 <span style="background-color:#000" class="dot2"></span> Base class object data structure comes inside derive class data structure which means drive class object grows biggers with more number of base classes where base class object stays separate in python.
 <span style="background-color:#000" class="dot2"></span> Python also supports virtual and polymorphism. runtime attribute addition to object makes it polymorphic where as c++ maintains a vtable for each virtual method entry in class definition.
 <span style="background-color:#000" class="dot2"></span> Default attributes and inheritance in c++ is private where as it is public in python </pre>
